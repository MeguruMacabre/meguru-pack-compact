# Meguru Pack Compact

**Meguru Pack Compact** - легковесный инструмент для распространения и автоматического обновления Minecraft-сборок, написанный на Go.

Позволяет владельцу публиковать обновления сборки в S3-совместимое хранилище, а пользователям — устанавливать и обновлять.

> **Статус:** v0.1.0 - в разработке.

## Установка и запуск

написать после 0.1.0

## Как это работает

### Host

Приложение для владельца сборки.

Сканирует Minecraft-инстанс, определяет изменения и загружает необходимые файлы в S3. Использует SHA-256 для проверки целостности и предотвращения повторной загрузки одинаковых файлов.

После успешной загрузки публикует обновлённый манифест, по которому клиенты определяют актуальное состояние сборки.

### Client

Приложение для пользователей сборки.

При первом запуске устанавливает сборку, а при последующих — проверяет доступные обновления и скачивает только необходимые файлы.

Система разделяет файлы на две категории:

- **Managed** — файлы, которыми управляет сборка (моды, ресурспаки и другие элементы).
- **Install-only** — файлы, которые устанавливаются один раз и сохраняются при обновлениях.

Пользовательские файлы и настройки должны оставаться нетронутыми.

## Состояние разработки

**Реализовано:**
- Сканирование файлов и вычисление SHA-256.
- Генерация манифеста сборки.
- Определение изменений (ADD / UPDATE / DELETE / KEEP).
- Подключение и публикация файлов в S3.
- Первоначальная публикация и последующие обновления.
- Пропуск загрузки уже существующих файлов и неизменённого манифеста.

**Планируется:**
- Разработка Client для установки и обновления сборок.
- Cинхронизация с сохранением пользовательских файлов.
- Параллельная загрузка и отправка файлов.
- Улучшение интерфейса, конфигурации и обработки ошибок.
- Доп тесты и оптимизация.
